# Internet Use and Mental Health in Adolescents
### Hours Online vs. the Feeling of Being Addicted

Final project — Data Analysis course. Authors: Noam Avizmil, Tomer Golshani, May Mandalaoui, Alina Kozitzyna.

## Research question

Is adolescent mental health more strongly associated with **how much** time is spent online
(raw exposure) or with the **subjective feeling of being addicted** (loss of control)? The two
are often conflated; we separate them in the same models and ask which one actually tracks
depression and loneliness, controlling for gender, physical activity, and offline relationships.

**Headline result:** perceived addiction (IAT) is strongly and robustly associated with depression
(adjusted standardized β = 0.51, 95% CI 0.44–0.57; E-value 2.55) and loneliness (β = 0.29); the
raw-hours measure is statistically *equivalent to zero* but is severely floor-constrained, so it is
too coarse to test the screen-time hypothesis rather than evidence that hours don't matter.
Logistic AUC = 0.78 (DeLong CI 0.74–0.81; CV 0.77).

## Data

`data/new_data.xlsx` — survey of **819 school students**, ages 13–19 (mean ~15.8), 534 female /
285 male. No missing values. Each row is one student.

Key variables used:

| Role | Variable(s) | Instrument |
|------|-------------|------------|
| Addiction (subjective) | `TotalIA` (0-94), `IAC` (category) | Internet Addiction Test (Young, 1998) |
| Depression (outcome) | `totalphq` (0-27), `categoryphq` | PHQ-9 (Kroenke et al., 2001) |
| Loneliness (outcome) | `lonelinesstotal` | UCLA Loneliness Scale (Russell, 1996) |
| Exposure (quantity) | `socialmediatime`, `internettime` | self-report, ordinal buckets |
| Controls | `gender`, `exercise`, `friendsrelationship` | self-report |

The IAT severity bands are heavily skewed toward "Normal" (only one student in the most-severe
band), so the **continuous** IAT score is used in all models; categories are used only as an
ordered descriptive lens. The prediction target, clinically-significant depression (PHQ-9 >= 10),
is well balanced (301/819 = 36.8%).

## Method

Framed as estimating the effect of perceived addiction (IAT) on depression and loneliness, with
quantity-of-use as a competing exposure:

- **Confounding:** DAG-justified back-door adjustment set {age, gender, bullied, physical activity}
  (`dagitty`); sleep treated as a mediator; **E-value** for unmeasured confounding (`EValue`).
- **Measurement validity:** Cronbach's alpha + McDonald's omega per scale from item-level data
  (`psych`); disattenuated correlations.
- **Effect sizes:** standardized betas with 95% CIs, incremental delta-R-squared + nested F,
  Cohen's f-squared (`effectsize`, `parameters`); HC3 robust SEs + Breusch-Pagan (`sandwich`,
  `lmtest`); **equivalence test (TOST)** for the hours null (it's a *floor effect*, ~62-84% in one
  bucket, not "no effect").
- **Prediction:** logistic for PHQ-9 >= 10 with ORs+CIs, **DeLong AUC CI** and repeated 10x10 CV
  (`pROC`); calibration (Hosmer-Lemeshow); proportional-odds model for severity (`MASS`/`ordinal`).
- **Robustness:** bootstrap BCa CIs (`boot`), influence diagnostics, BH multiplicity correction,
  no-separation check.
- **Ordered-factor visualizations** (jitter + boxplots) for severity; no bar charts.

## Reproduce

```r
# R 4.x. Install once:
install.packages(c("tidyverse","readxl","psych","dagitty","sandwich","lmtest",
  "effectsize","parameters","performance","pROC","EValue","boot","MASS",
  "ordinal","ResourceSelection","broom"))
Rscript analysis.R
```

Inferential estimates use the full sample; AUC uses repeated cross-validation; all randomness is
seeded (`set.seed(42)`). The script prints every coefficient, reliability, E-value, AUC and
severity number reported in `REPORT.docx`, with expected values noted as comments, and writes the
figures to `figures/`.
