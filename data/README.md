# Data placement

This project relies on `new_data.xlsx` (a survey of 819 school students:
IAT internet-addiction, PHQ-9 depression, UCLA loneliness, plus demographics
and behaviour).

**The data file is intentionally NOT committed to this repository** (per course
requirements).

To reproduce the analysis:
1. Download `new_data.xlsx` from the project data folder:
   <PASTE GOOGLE-DRIVE DATA-FOLDER LINK HERE>
2. Place it at: `data/new_data.xlsx`
3. Run `Rscript analysis.R` from the repository root.
